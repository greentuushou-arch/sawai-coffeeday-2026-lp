# 澤井珈琲「コーヒーの日」星降るブレンド 特別キャンペーンLP

10月1日「コーヒーの日」限定、星降るブレンド(カシオペア・サザンクロス・星ロマン 飲み比べ3種60杯分福袋)のポイント2倍・2,026円OFFクーポン特集ページです。

## ファイル構成

```
index.html          … 特集ページ本体(HTML+CSS+JS、すべてこの1ファイルに含まれています)
images/
  header/            … ヘッダーのロゴ画像
  product/            … 商品写真(楽天商品ページ掲載の公式画像を加工して使用)
```

`index.html` を丸ごと(`images/` フォルダごと)サーバーにアップロードしてください。パスはすべて相対パスなので、どのディレクトリに置いても動作します。

## 設定済みの内容

- **クーポン取得URL**は未設定です(`#` のまま)。下記「編集箇所の探し方」を参照し、発行後のURLに差し替えてください。
- **商品ページURL**は設定済みです(`https://item.rakuten.co.jp/sawaicoffee-tea/dp-seizablend3s60/`)。
- **カウントダウン**は 2026年10月1日 0:00〜23:59 に設定済みです。
  - 開催前:「コーヒーの日 開始まで あと○日○時間○分」
  - 開催中:「コーヒーの日 終了まで あと○時間○分○秒」(1秒ごとに更新)
  - 終了後:カウントダウンとクーポンボタンが自動的に無効化されます

## ご対応・ご確認いただきたい項目

### 1. クーポン取得URLの設定(必須)

`index.html` 内の `<script>` タグ内、`COUPON_URL` を実際のクーポン取得URLに書き換えてください。現在は `"#"` のままなので、クーポンボタンを押しても何も起きません。

### 2. 販売実績カウンターの表示(任意)

```js
const SOLD_COUNT = 0;      // 現在の販売数(0のあいだは非表示)
const SOLD_TARGET = 2000;  // 目標販売数
```

`SOLD_COUNT` を実際の販売数に書き換えると、進捗バーが表示されます。**0のあいだは非表示**です。

### 3. 期間・価格・クーポンの最終確認

| 項目 | 現在の設定 |
|---|---|
| 開催日 | 2026年10月1日 0:00〜23:59 |
| 通常価格 | 4,928円 |
| クーポン | 2,026円OFF・ポイント2倍 |
| クーポン適用後価格 | 2,902円 |
| 内容量 | 3種×20袋(60杯分) |

※クーポン適用後価格(2,902円)は 4,928円−2,026円 で表示しています。楽天の端数処理と一致するかご確認ください。

### 4. レビューの数値について

レビューブロックの「総合評価4.50(8件)」および引用2件は、掲載時点の楽天レビューを元にしたテキストです。最新の数値・声に更新する場合は `index.html` 内の `REVIEW` セクションを直接編集してください。

## 実装上のご注意

- **JavaScriptを使用しています。** カウントダウン、クーポンURLの一括設定、FVの流れ星演出にJSを使っています。JavaScriptが実行できない環境には設置できませんのでご留意ください。
- レスポンシブ対応済みで、スマホ表示を基準に作成し、768px以上でPC向けレイアウトに切り替わります。
- 見出し等のフォントに Google Fonts(Josefin Sans / Kaisei Opti / Zen Kaku Gothic New)を外部読み込みしています。インターネット接続がある環境であれば通常表示され、読み込めない場合は端末の標準フォントで表示されます。
- ファーストビュー・最終ブロックの商品写真は、楽天商品ページ(`dp-seizablend3s60`)に掲載されている公式画像を、バッジ等を除いてトリミング加工したものです。
